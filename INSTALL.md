# Установка

Кодер ставят, когда в контуре есть правила по стране или системе и когда оператору нужна
карточка адреса в панели. Обычно его поднимает фундамент установки (`placitum-core`).

## Что нужно рядом

| Компонент | Обязателен | Зачем |
| --- | --- | --- |
| Каталог: страны и системы | для осмысленных ответов | выгрузка из панели или два каталога файлов; без них кодер отвечает «неизвестно» |
| NATS | нет | журнал, живой уровень, кадр присутствия и документ `policy/geo`: без шины выгрузка из панели до кодера не доезжает |
| Контроллер | нет | ходит в HTTP за карточкой адреса; у него кодер скачивает выгрузки, загруженные в панель |

Базы у кодера нет. Памяти нужно столько, сколько весит каталог в разложенном виде: миллион
префиксов укладывается примерно в 70 МиБ, и на стенде процессу дают 4 ГБ с `GOMEMLIMIT=3GiB`.
На время подмены выгрузки в памяти два набора таблиц одного вида — прежний и новый.

## Переменные

| Переменная | По умолчанию | Что |
| --- | --- | --- |
| `WAF_GEO_COUNTRY` | `./data/country` | каталог с префиксами стран. Каталог должен существовать, иначе процесс не стартует |
| `WAF_GEO_ASN` | `./data/asn` | каталог с анонсами автономных систем |
| `WAF_GEO_CONTROLLER_URL` | `http://controller:8080` в образе | откуда скачивать выгрузки, загруженные в панель; пусто — не скачивать и жить на каталогах |
| `WAF_GEO_FETCH_DIR` | `/var/lib/waf/geo` в образе | куда класть скачанные копии; последняя целая поднимается при старте раньше каталогов |
| `WAF_GEO_HTTP` | `:8092` | HTTP: карточка адреса для панели, `/healthz` |
| `WAF_GEO_GRPC` | `:50051` | gRPC: `geo.v1.Geo/Lookup` для инспекторов |
| `WAF_GEO_RELOAD_EVERY` | — | как часто перечитывать каталог |
| `WAF_NATS_URL` | `nats://127.0.0.1:4222` | шина: журнал и кадр присутствия |
| `WAF_GEO_LOG` | `info` | уровень журнала |
| `WAF_SERVICE_NAME` | `geo` | имя в кадре присутствия |
| `GOMEMLIMIT` | — | мягкий потолок кучи: ставьте примерно в три четверти лимита контейнера |

В образе каталоги данных **не создаются**: их монтируют снаружи. Это осознанно — выгрузки
лицензируются отдельно и в образ не едут. Каталог копий (`/var/lib/waf/geo`) в образе есть и
принадлежит процессу; том на него сохраняет копию между пересозданиями контейнера.

## Каталог

Выгрузку GeoLite2 оператор загружает в панели: «Наборы адресов → Гео» и «→ ASN», кнопка
«Загрузить данные». Контроллер сверяет с файлом каталог своей базы, кладёт рядом сам файл и
называет его документом `policy/geo` в KV `WAF_DESIRED`. Кодер на каждую ревизию документа:

1. скачивает копию `GET <контроллер>/api/geo/files/<вид>` во временный файл;
2. сверяет размер и хеш с документом — не сошлось, значит контроллер уже держит файл новее, и
   документ о нём на подходе;
3. собирает таблицы этого вида рядом с действующими — запросы всё это время идут по прежним;
4. подменяет снимок разом и только после этого удаляет прежнюю копию.

Сорвалось (контроллер недоступен, хеш не тот) — кодер остаётся на том, что держит, и повторяет
с отступом от секунды до полуминуты. Копии лежат в `WAF_GEO_FETCH_DIR` и переживают рестарт.

Каталоги в `/app/data` — запасной путь: на них кодер живёт до первой загрузки и там, где
контроллера нет. Пустые каталоги — рабочее состояние: правила по стране и системе тогда
отвечают отказом с машинным кодом, а остальное работает.

## Docker Compose

```yaml
services:
  geo:
    image: placitum/geo
    environment:
      WAF_NATS_URL: nats://nats:4222
      WAF_GEO_CONTROLLER_URL: http://controller:8080
      WAF_GEO_LOG: info
      GOMEMLIMIT: 3GiB
    volumes:
      - ./geo-data:/app/data:ro
      - geo-copies:/var/lib/waf/geo
    mem_limit: 4g

volumes:
  geo-copies:
```

Порты наружу не нужны: в кодер ходят инспекторы и контроллер изнутри сети.

## Проверка после запуска

```sh
curl -fsS http://127.0.0.1:8092/healthz

# Карточка адреса: страна, система, префикс
curl -fsS 'http://127.0.0.1:8092/lookup?addr=8.8.8.8'
```

Пустой ответ на живой адрес означает пустой каталог, а не поломку: смотрите в журнал строку о
том, сколько записей загружено.

По какой выгрузке кодер отвечает — в кадре присутствия: `work.country_sha256` и
`work.asn_sha256` (пусто — каталог из окружения) и `conf` — ревизия документа `policy/geo` и
исход (`ok`, `fetching`, `fetch_failed`). Панель сверяет эти хеши с загруженным файлом и
показывает, сколько копий кодера уже на нём.

## Грабли

- **Каталоги обязаны существовать.** Не файлы — каталоги; пустые допустимы, отсутствующие нет.
- **Выгрузка из панели ходит только по шине.** Без NATS документ `policy/geo` не читается, и
  кодер остаётся на каталогах; панель покажет это как «кодер 0 из 1».
- **Ожидание синхронное.** Инспектор ждёт кодер внутри бюджета сообщения, и бюджет по умолчанию
  полсекунды — это не «сколько он думает», а запас на дурную минуту сети. Сам ответ стоит доли
  миллисекунды.
- **DNS в контуре.** Медленный резолв имени `geo` бьёт по тому же бюджету: на стенде сотню
  миллисекунд однажды съедал лишний TXT-запрос докерского DNS.
