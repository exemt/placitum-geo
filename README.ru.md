# Placitum geo

[English](README.md) · Русский

Справочник сетей Placitum: страна и номер автономной системы по адресу клиента.

Отвечает двоим: инспекторам по gRPC — когда правило пишет в набор не адрес, а подсеть или систему
целиком, — и панели по HTTP, для карточки адреса. В путь запроса не встаёт.

```
инспектор ──gRPC :50051──►  geo  ◄──HTTP :8092── контроллер (карточка адреса)
                             │ ▲
                             │ └── копия выгрузки из панели: KV policy/geo → GET /api/geo/files/<вид>
                             └── каталог: префиксы стран и анонсы систем
```

Каталог — не база и не сеть: файлы на диске, которые процесс держит в памяти и перечитывает
сам. Пустой каталог — рабочее состояние: справочник сетей отвечает «неизвестно», и правила, которым он
нужен, явно отвечают ошибкой, а не молчат.

Выгрузку MaxMind оператор загружает в панель. Справочник сетей узнаёт о ней документом в KV, скачивает
копию у контроллера, собирает таблицы рядом с действующими и подменяет их; до подмены отвечает
по прежним.

## Сборка и запуск

```sh
docker build -t placitum/geo .
docker run --rm -p 8092:8092 -p 50051:50051 \
  -v /path/country:/app/data/country:ro \
  -v /path/asn:/app/data/asn:ro \
  placitum/geo
```

Что нужно рядом, настройки и откуда берётся каталог — в [INSTALL.ru.md](INSTALL.ru.md).

## API

gRPC `geo.v1.Geo/Lookup` (`proto/geo.proto`) и те же данные по HTTP:

| Запрос | Что |
| --- | --- |
| `GET /lookup?addr=8.8.8.8` | адрес или CIDR; `expand=asn` добавляет состав системы целиком |
| `POST /lookup/batch` с `{"addrs": [...]}` | до 500 адресов одним запросом; некорректный адрес размечает только свой элемент |
| `GET /healthz` | живость |

```json
{
  "gen": 17,
  "countries": [{"code": "us", "name": "United States"}],
  "asns": [
    {"asn": 15169, "name": "GOOGLE", "prefix": "8.8.8.0/24",
     "effective": true, "range": {"start": "8.8.8.0", "end": "8.8.8.255"}},
    {"asn": 3356, "name": "LEVEL3", "prefix": "8.0.0.0/9"}
  ]
}
```

На адрес ответ перечисляет все накрывающие его анонсы, от самого узкого к самому широкому;
эффективный идёт первым и несёт `range`. На диапазон каждая система встречается один раз.
Неизвестный адрес — пустые списки, а не ошибка; некорректный ввод — `400` или `InvalidArgument`. `gen`
меняется вместе с каталогом, и клиенты сбрасывают свои кэши.

## Форматы каталога

Путь может указывать на каталог, `.tsv` или `.mmdb`; формат определяется по тому, что лежит на
диске.

| Источник | Страны | ASN |
| --- | --- | --- |
| Каталог | `<код>.txt` или `<код>/ranges.txt` | `<номер>.txt` или `<номер>/ranges.txt` |
| TSV | выгрузка контроллера: `code type address name` | то же, `code` — номер AS |
| MMDB | `GeoLite2-Country.mmdb` | `GeoLite2-ASN.mmdb` |

Текстовый файл — один префикс или адрес на строку; `#` — комментарий, `# name: United States`
задаёт подпись. Код страны — ISO 3166-1 alpha-2 в нижнем регистре.

## Что нужно знать

- **Ответ стоит доли миллисекунды**, но инспектор ждёт его синхронно, в бюджете сообщения:
  промах справочника сетей — это ошибка строки правила, а не задержка запроса.
- **Каталог обновляется на ходу.** Загрузили выгрузку в панели или положили файлы в каталог —
  процесс подхватит их сам, рестарт не нужен.
- **Своего состояния нет.** Реплик может быть сколько угодно, каждая со своим каталогом.
