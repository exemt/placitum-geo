# Установка

[English](INSTALL.md) · Русский

Справочник сетей ставят, когда правила работают со странами или автономными системами и когда оператору
нужна карточка адреса в панели. Обычно его ставит `placitum-core`.

## Что нужно рядом

| Компонент | Обязателен | Зачем |
| --- | --- | --- |
| Каталог стран и систем | для осмысленных ответов | выгрузка из панели или два пути к каталогу; без них справочник сетей отвечает «неизвестно» |
| NATS | нет | журнал, живой уровень, кадр присутствия и документ `policy/geo`; без шины выгрузка из панели до справочника сетей не доходит |
| Контроллер | нет | ходит по HTTP за карточкой адреса; у него справочник сетей скачивает выгрузки, загруженные в панель |

Базы у справочника сетей нет. Памяти нужно столько, сколько весит каталог в разложенном виде: миллион
префиксов укладывается примерно в 70 МиБ, а установка из core даёт процессу 4 ГБ с
`GOMEMLIMIT=3GiB`. На время подмены в памяти два набора таблиц одного вида.

## Настройки

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `WAF_GEO_COUNTRY` | `./data/country`; в образе `/app/data/country` | каталог стран: каталог, TSV или `GeoLite2-Country.mmdb`; путь обязан существовать |
| `WAF_GEO_ASN` | `./data/asn`; в образе `/app/data/asn` | каталог систем; путь обязан существовать |
| `WAF_GEO_CONTROLLER_URL` | пусто; в образе `http://controller:8080` | откуда скачивать выгрузки, загруженные в панель; пусто — жить на каталогах |
| `WAF_GEO_FETCH_DIR` | `./data/fetched`; в образе `/var/lib/waf/geo` | скачанные копии; последняя целая при старте выигрывает у каталогов |
| `WAF_GEO_HTTP` | `:8092` | HTTP: карточка адреса и `/healthz`; пусто — не слушать |
| `WAF_GEO_GRPC` | `:50051` | gRPC `geo.v1.Geo/Lookup` для инспекторов; пусто — не слушать |
| `WAF_GEO_RELOAD_EVERY` | `1s` | как часто проверять файлы каталога |
| `WAF_NATS_URL` | `nats://127.0.0.1:4222`; в образе `nats://nats:4222` | шина; пустое значение её выключает |
| `WAF_GEO_LOG` | `info` | уровень журнала |
| `WAF_SERVICE_NAME` | `geo` | имя в кадре присутствия |
| `WAF_HEARTBEAT_EVERY` | `4s` | период кадра присутствия |
| `GOMEMLIMIT` | — | мягкий предел кучи: примерно три четверти лимита контейнера |

В образе каталоги данных не создаются: их монтируют снаружи. Выгрузки лицензируются отдельно и в
образ не уходят. Каталог копий `/var/lib/waf/geo` в образе есть и принадлежит процессу; том на нём
сохраняет копию между пересозданиями контейнера.

## Каталог

Выгрузку GeoLite2 оператор загружает в панели. Контроллер сверяет файл со своим каталогом, кладёт
файл рядом и называет его документом `policy/geo` в KV `WAF_DESIRED`. На каждую ревизию документа
справочник сетей:

1. скачивает `GET <контроллер>/api/geo/files/<вид>` во временный файл;
2. сверяет размер и хеш с документом; не сошлось — значит, у контроллера уже файл новее и документ
   о нём на подходе;
3. собирает таблицы этого вида рядом с действующими, а запросы всё это время идут по прежним;
4. подменяет снимок разом и только после этого удаляет прежнюю копию.

Сорвалось (контроллер недоступен, хеш не тот) — справочник сетей остаётся на том, что держит, и повторяет с
отступом от секунды до полуминуты. Копии в `WAF_GEO_FETCH_DIR` переживают рестарт.

Каталоги в `/app/data` — запасной путь: на них справочник сетей живёт до первой загрузки и там, где
контроллера нет. Пустые каталоги — рабочее состояние: правила по стране и системе отвечают
ошибкой с машинным кодом, остальное работает.

## Docker Compose

```yaml
services:
  geo:
    image: placitum/geo
    environment:
      WAF_NATS_URL: nats://nats:4222
      WAF_GEO_CONTROLLER_URL: http://controller:8080
      WAF_GEO_LOG: info
      GOMEMLIMIT: 3GiB
    volumes:
      - ./geo-data:/app/data:ro
      - geo-copies:/var/lib/waf/geo
    mem_limit: 4g

volumes:
  geo-copies:
```

Порты наружу не нужны: в справочник сетей ходят инспекторы и контроллер изнутри сети.

## Проверка

```sh
curl -fsS http://127.0.0.1:8092/healthz
curl -fsS 'http://127.0.0.1:8092/lookup?addr=8.8.8.8'
```

Пустой ответ на живой адрес означает пустой каталог, а не поломку: в журнале есть строка о том,
сколько записей загружено.

По какой выгрузке справочник сетей отвечает — видно в кадре присутствия: `work.country_sha256` и
`work.asn_sha256` (пусто — каталоги) и `conf` с ревизией документа `policy/geo` и исходом (`ok`,
`fetching`, `fetch_failed`). Панель сверяет эти хеши с загруженным файлом.

## Типичные ошибки

- **Пути каталога обязаны существовать.** Пустые каталоги допустимы, отсутствующие — нет.
- **Выгрузка из панели ходит только по шине.** Без NATS документ `policy/geo` не читается, и справочник сетей
  остаётся на каталогах.
- **Ожидание синхронное.** Бюджет по умолчанию в полсекунды — это запас на дурную минуту сети, а
  не время на раздумья: сам ответ стоит доли миллисекунды.
- **DNS в установке.** Медленный резолв имени `geo` бьёт по тому же бюджету.
