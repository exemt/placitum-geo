# placitum/geo

Кодер гео Placitum: страна и номер автономной системы по адресу клиента.

Отвечает двоим: инспекторам по gRPC — когда правило пишет в набор не адрес, а подсеть или
систему, — и панели по HTTP, для карточки адреса. В горячий путь модуля не встаёт.

```
инспектор ──gRPC :50051──►  geo  ◄──HTTP :8092── контроллер (карточка адреса)
                             │
                             └── каталог: префиксы стран и анонсы систем
```

Каталог — не база и не сеть: два файла на диске, которые процесс держит в памяти и перечитывает
сам. Пустой каталог — рабочее состояние: кодер отвечает «неизвестно», и правила, которым он
нужен, честно отвечают отказом, а не молчанием.

## Сборка и запуск

```sh
docker build -t placitum/geo .
docker run --rm -p 8092:8092 -p 50051:50051 \
  -v /path/country:/app/data/country:ro \
  -v /path/asn:/app/data/asn:ro \
  placitum/geo
```

Что нужно рядом, переменные и откуда берётся каталог — [INSTALL.md](INSTALL.md).

## Что нужно знать

- **Ответ стоит доли миллисекунды**, но инспектор ждёт его синхронно, в бюджете сообщения:
  промах кодера — это отказ строки правила, а не задержка запроса.
- **Каталог обновляется на ходу.** Залили новую выгрузку — процесс подхватит её сам, рестарт не
  нужен.
- **Своего состояния нет.** Реплик может быть сколько угодно, каждая со своим каталогом.
